## PID Simulation
### This is a quick 'n dirty, time limited, AI vibecoded, side project. Use at your own risk.

A browser-based liquid tank level control simulator. Tune the PID controller's proportional gain (Kp), integral time (Ti), and derivative time (Td), then observe how the measured tank level responds to the setpoint. The live trend chart plots the measured value, setpoint, and controller output; you can hide traces, freeze the chart, or adjust its sampling interval.

Switch between automatic PID control and manual output to experiment with the simulated valve and tank dynamics. This is an educational demonstration, not a model for real process control.
